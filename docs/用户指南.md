# 晨曦画笔 — 用户指南

**晨曦画笔**是一款面向 Chrome / Edge（Chromium 内核）的浏览器扩展，可在任意网页上叠加透明绘图层，用画笔、几何图形、表格、坐标系、文字等工具做临时标注，适合讲课演示、在线协作、资料批注等场景。

当前版本：**1.8.6**（以扩展管理页显示为准）

---

## 产品优势

| 优势 | 说明 |
|------|------|
| **即开即用** | 无需安装独立软件，在浏览器里一键进入标注模式，不离开当前网页。 |
| **工具齐全** | 双画笔、双荧光笔、直线、矩形、箭头线、圆形、表格、坐标系（含刻度数字）、文字、橡皮擦，覆盖常见讲解与批注需求。 |
| **不打扰浏览** | 默认「鼠标模式」：可正常点击链接、滚动页面；需要绘制时再切换到「画笔模式」。 |
| **可编辑对象** | 直线、矩形、表格、坐标系、文字等可点选、拖动；文字支持双击再编辑。 |
| **手写风格文字** | 内置寒蝉手拙体，标注文字更贴近板书效果（系统已安装同名字体时会优先使用系统字体）。 |
| **高效操作** | 悬浮工具栏可拖动；各工具支持自定义快捷键；撤销 / 重做、隐藏笔记、导出 PNG。 |
| **隐私友好** | 标注内容仅保存在当前页面的内存中，**不会上传**到服务器；扩展只申请 `storage`（保存你的颜色、快捷键等偏好）和 `activeTab`。 |
| **轻量稳定** | 原生 JavaScript + Canvas，无重型框架，注入快、占用小。 |

## 环境要求

- **浏览器**：Google Chrome 或 Microsoft Edge（及其他基于 Chromium 的浏览器）
- **页面**：支持 `http://`、`https://` 等普通网页
- **不支持**：`chrome://`、`edge://`、部分内置 PDF 查看器、无法注入脚本的 iframe 内页面等（此类页面扩展无法工作）

## 安装步骤

### 方式一：从发布包安装（推荐）

1. 获取安装包（例如 `huabi-1.8.x.zip`），解压到任意文件夹（路径中尽量避免中文乱码或过长路径）。
2. 打开浏览器扩展管理页：
   - **Chrome**：地址栏输入 `chrome://extensions/`
   - **Edge**：地址栏输入 `edge://extensions/`
3. 打开右上角 **「开发者模式」**。
4. 点击 **「加载已解压的扩展程序」**（Edge 文案可能为「加载解压缩的扩展」）。
5. 选择解压后的文件夹（内含 `manifest.json` 的那一层，不要只选子目录）。
6. 安装成功后，工具栏会出现 **晨曦画笔** 图标；建议点击图钉固定，便于使用。

### 方式二：从源码目录安装（开发者）

若你持有完整项目源码，在 `huabi` 项目根目录（含 `manifest.json`）执行「加载已解压的扩展程序」即可，步骤同上。

### 更新扩展

1. 下载新版本 zip 并解压（可覆盖原文件夹，或解压到新目录）。
2. 在扩展管理页找到「晨曦画笔」，点击 **「重新加载」**（若更换了文件夹路径，需先移除旧扩展再重新加载新目录）。

## 快速开始

1. 打开需要标注的网页（如在线文档、教学平台、网页版 PPT 等）。
2. **进入标注模式**（任选其一）：
   - 点击浏览器工具栏上的 **晨曦画笔** 图标；
   - 使用快捷键 **Alt+Shift+D**（可在浏览器扩展快捷键设置中修改）。
3. 页面顶部会出现 **悬浮工具栏**，画布覆盖当前窗口可视区域。
4. 首次进入默认为 **鼠标模式**：可以照常操作网页；点击标注过的线条、文字等可选中并拖动。
5. 点击工具栏上的 **指针/画笔切换** 按钮，或按 **空格**（默认），切换到 **画笔模式** 开始绘制。
6. 标注结束后：
   - 再次点击扩展图标或 **Alt+Shift+D** 退出标注模式；
   - 或点击工具栏 **关闭** 按钮。
7. **刷新页面或关闭标注后，当前页标注会清空**；需要保留请使用工具栏 **保存** 导出 PNG。

## 工具栏说明

工具栏可拖动左侧把手调整位置。主要按钮从左到右大致为：

| 区域 | 功能 |
|------|------|
| 拖动手柄 | 移动工具栏位置 |
| 鼠标/画笔 | 在「鼠标模式」与「画笔模式」间切换 |
| 画笔 1 / 画笔 2 | 两种预设颜色的自由画笔 |
| 荧光笔 1 / 荧光笔 2 | 半透明高亮笔迹 |
| 形状工具 | 直线、矩形、表格、坐标系、文字等（可在设置中显示/隐藏部分按钮） |
| 橡皮擦 | 擦除笔迹 |
| 撤销 / 重做 | 回退或恢复操作 |
| 全部清除 | 清空当前页所有标注 |
| 隐藏笔记 | 临时隐藏标注层（便于查看网页内容），再按一次恢复 |
| 保存 | 导出当前标注为 PNG（透明背景） |
| 设置 | 打开颜色、快捷键、工具栏显示等配置 |
| 关闭 | 退出标注模式 |

### 样式微调（▾）

画笔、荧光笔、直线、矩形、箭头线、圆形、表格、坐标系、文字、橡皮擦等工具按钮旁有 **▾**，点击可设置：

- **线宽**、荧光笔 **透明度**
- **表格**：行数、列数（拖拽绘制外框后自动生成网格）
- **坐标系**：刻度数、起始值、跨度、是否显示 Y 轴及刻度
- **文字**：字号（0 表示按网页自动估算）
- **箭头直线**：单端或双端箭头

## 各工具使用方法

### 画笔 / 荧光笔

- 切换到画笔模式，选择画笔或荧光笔，在页面上按住拖动即可书写。
- 颜色在 **设置** 中为「画笔 1 / 2」「荧光笔 1 / 2」分别配置（各 3 个保存色 + 当前色）。

### 直线 / 矩形 / 圆形 / 箭头直线

1. 选中对应工具。
2. 在画布上 **按下起点 → 拖动预览 → 松开** 完成绘制。
3. 绘制后通常会自动回到鼠标模式，便于选中、移动图形；可在该工具的 ▾ 面板中查看说明。

### 表格

1. 在 ▾ 中设置行数、列数。
2. 拖拽划定表格外框，松开后按行列均分画线。

### 坐标系

1. 在 ▾ 中设置线宽、刻度数、起始值、跨度，可选 **显示 Y 轴**。
2. 拖拽划定坐标区域。
3. **仅 X 轴**：刻度从左起按「起始值 + i × 跨度」标注（默认 0, 1, 2…）。
4. **含 Y 轴**：交点为原点，X 轴向下为负、向右为正；Y 轴在左侧，向上为正、向下为负。

### 文字

1. 选择文字工具，在画笔模式下 **点击** 放置文字（或点击已有文字进行编辑）。
2. 支持多行输入；**双击** 已放置文字可再次编辑。
3. 颜色跟随当前主画笔（画笔 1 或画笔 2）；字号在 ▾ 或设置中调整。
4. **Delete / Backspace** 可删除当前选中的文字或图形。

### 橡皮擦

在画笔模式下拖动擦除笔迹（与画笔类似的操作方式）。

## 鼠标模式与画笔模式

| 模式 | 用途 |
|------|------|
| **鼠标模式** | 正常浏览网页：点击链接、滚动、选择页面内容；点中已有标注可选中、拖动。 |
| **画笔模式** | 使用当前工具绘制；文字工具下点击空白新建、单击选中拖动、双击编辑。 |

- 切换方式：工具栏 **鼠标/画笔** 按钮，或默认快捷键 **空格**。
- 选择某一绘制工具时，通常会 **自动进入画笔模式**。

## 设置与快捷键

### 打开设置

- 标注模式下点击工具栏 **设置（齿轮）**；
- 或在扩展管理页点击「晨曦画笔」的 **扩展选项**（独立标签页，内容与工具栏设置相同）。

### 可配置项

- **画笔颜色**：四套笔的颜色预设
- **工具栏显示**：勾选要在工具栏上显示的形状类工具（箭头线、圆形等默认可能隐藏，可用快捷键仍可调出）
- **快捷键**：为切换模式、各工具、撤销、导出等绑定按键（修改后自动保存）

### 默认快捷键参考

| 功能 | 默认按键 |
|------|----------|
| 浏览器全局：切换标注模式 | Alt+Shift+D |
| 切换鼠标/画笔 | 空格 |
| 画笔 1 / 画笔 2 | 1 / 2 |
| 荧光笔 1 / 荧光笔 2 | 3 / 4 |
| 直线 / 矩形 / 表格 / 坐标系 / 文字 | L / R / T / G / I |
| 橡皮擦 | E |
| 隐藏/显示笔记 | V |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 导出 PNG | Ctrl+S |

> 工具快捷键仅在 **画笔模式** 下生效。Ctrl+T、Ctrl+W 等由浏览器占用的组合无法用于标注，请在设置中改用其他组合（如 Alt+字母）。

设置保存在本机浏览器中；若登录 Chrome 账号并开启同步，部分偏好可同步到其他设备。

## 导出与保存

- 点击工具栏 **保存**，会下载 PNG 文件（文件名形如 `晨曦画笔-时间戳.png`）。
- 导出内容为 **标注层合成图**（透明背景），不含网页原始截图；导出时会暂时隐藏工具栏，避免工具栏入画。
- 标注 **不会自动写入网页**，也不会在刷新后保留；重要内容请务必导出或自行截图备份。

## 使用限制与说明

1. **单页临时性**：标注存在内存中，刷新、关闭标签页或退出标注模式会丢失。
2. **视口范围**：画布覆盖当前窗口可见区域；页面很长时，滚动后新区域需重新标注（或滚动回原区域查看原标注）。
3. **特殊页面**：无法在浏览器内部页、部分 PDF、跨域 iframe 中使用，属浏览器安全限制。
4. **版本升级**：升级扩展后，旧会话中绘制的部分笔迹可能 **无法点选编辑**；新绘制内容支持选中、移动与删除。
5. **权限说明**：扩展不读取或上传页面内容；`storage` 仅用于保存你的工具偏好。

## 常见问题

**Q：点击扩展图标没有反应？**  
A：请刷新目标网页后再试；确认页面不是 `chrome://` 等受限地址。若仍无效，在扩展管理页「重新加载」扩展。

**Q：标注挡住了网页，我想先看内容？**  
A：使用工具栏 **隐藏笔记**，或切换到鼠标模式操作页面。

**Q：如何只保留标注、不要网页背景？**  
A：使用 **保存** 导出 PNG，即为透明底标注图。

**Q：箭头线、圆形在工具栏里看不到？**  
A：打开 **设置 → 工具栏显示**，勾选「箭头直线」「圆形」；或使用你为这些工具配置的快捷键。

**Q：快捷键不生效？**  
A：确认已进入标注模式且处于 **画笔模式**（切换鼠标/画笔的快捷键在标注开启后始终可用）。避免与浏览器自带快捷键冲突。

**Q：能否把标注嵌进网页永久保存？**  
A：当前版本不支持写入网页 DOM；请使用导出 PNG，或在目标系统中自行粘贴图片。
