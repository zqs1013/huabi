# 清松手写体1

文字工具默认字体：**清松手写体1**（游清松 / Jason Handwriting 1）。

- 不可单独出售字体文件。详见 [GitHub jasonhandwriting/JasonHandwriting](https://github.com/jasonhandwriting/JasonHandwriting)。

## 扩展内字体文件

本目录已包含 `QingSongShouXieTi1.ttf`（与 [字体天下](https://www.fonts.net.cn/font-37790278130.html) 所列 `QingSongShouXieTi1-2.ttf` 为同一套「清松手写体1」）。

若需更新：从官方仓库下载 `JasonHandwriting1.ttf` 覆盖本文件即可。

## 系统已安装字体时

若 Windows 已安装「清松手写体1」，扩展会优先使用系统字体，无需依赖上述文件。
